OverTheWire: Bandit — Levels 0 through 10

A walkthrough of the first ten Bandit levels: SSH connection basics, hidden files, permission traps, and command chaining under a restricted environment.

Objective

Bandit is a beginner wargame hosted by OverTheWire designed to teach the basics of Linux commands needed to navigate later, more advanced challenges. Each level requires finding a password hidden somewhere on the filesystem to log into the next level via SSH.
