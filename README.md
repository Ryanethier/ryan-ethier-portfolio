## Repository Structure

```
index.html                       # Homepage
digital-forensics-report.pdf     # Full digital forensics case report
assets/
  style.css                      # Shared stylesheet
  favicon.svg
projects/
  ctf-writeups/
    index.html                   # CTF write-up listing
    bandit-0-10.html             # Individual write-up
resume/
  resume.pdf                     # Not yet added — see resume/README.md
robots.txt
sitemap.xml
README.md
```

Adding a new project: create a folder under `projects/`, build an `index.html` there using
`assets/style.css`, then add a card linking to it from the homepage's Projects section.
